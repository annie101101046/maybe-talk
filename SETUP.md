# Maybe She'd Like to Talk

Static landing page for the 40-week interactive pregnancy journey: a weekly emotional guide, plus breathing and meditation practices.

Contact: [hello@maybeshedliketotalk.org](mailto:hello@maybeshedliketotalk.org)

## Deploying

The site deploys on Vercel from `main`. Push to `main` and Vercel publishes `index.html`.

Domain: [maybeshedliketotalk.org](https://maybeshedliketotalk.org)

## File structure
